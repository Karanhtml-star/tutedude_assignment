# 🎨 CSS Selectors Demo

A simple HTML project demonstrating different types of **CSS selectors**.

## 🚀 Features

* Element selector (`p`)
* Class selector (`.head`, `.brown`)
* ID selector (`#para`, `#bglime`)
* Nested & span styling
* Anchor tag styling without class/id
* List styling examples

## 🛠️ Tech Used

* HTML5
* CSS3

## ▶️ Run

Open `index.html` in your browser.
