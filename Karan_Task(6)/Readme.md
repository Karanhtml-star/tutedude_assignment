# 🔐 Login Page (Flexbox Based)

A simple and modern **Login Page UI** built using **HTML5** and **CSS3 (Flexbox)**.
This project focuses on layout structuring, alignment, and responsive design basics.

---

## 🚀 Features

* 💻 Clean two-column layout using **Flexbox**
* 🎨 Gradient background design
* 📱 Basic responsive structure
* 🧾 Simple login form (Email & Password)
* 🔘 Styled button and interactive input fields
