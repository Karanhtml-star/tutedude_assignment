# 🎨 Animation & UI Feedback Showcase

A modern collection of **Tailwind CSS animations, hover effects, loading states, notification badges, and interactive UI components**. This project demonstrates how to create smooth, responsive, and engaging user interfaces using only **HTML** and **Tailwind CSS**.

---

## 🚀 Features

### 🔄 Built-in Tailwind Animations

* `animate-spin` – Loading spinner
* `animate-ping` – Notification indicator
* `animate-pulse` – Online/active status
* `animate-bounce` – Scroll indicator & attention-grabbing animation

### 🎯 Button Hover Effects

* Scale animation
* Shadow enhancement
* Color transitions
* Rotation effect
* Lift (Translate Y)
* Combined hover effects

### 🃏 Card Animations

* Lift with shadow
* Scale & rotate
* Border reveal
* Smooth transitions

### 🔔 Notification Badges

* Animated notification dot
* Pulsing online status
* Bouncing notification count

### ⏳ Loading States

* Skeleton loading card
* Loading button with spinner

## 📚 Tailwind Utilities Used

### Animation

* `animate-spin`
* `animate-ping`
* `animate-pulse`
* `animate-bounce`

### Transform

* `hover:scale-110`
* `hover:-translate-y-4`
* `hover:rotate-12`

### Transition

* `transition-all`
* `transition-shadow`
* `transition-colors`
* `duration-300`
* `ease-in-out`

### Shadow

* `shadow-md`
* `shadow-xl`
* `hover:shadow-2xl`
