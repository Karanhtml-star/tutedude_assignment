# JavaScript Number Programs – Assignment

## Objective

The objective of this assignment is to practice **basic JavaScript programming concepts** such as loops, conditional statements, and arithmetic operations by solving different number-based problems.

---

## Programs Implemented

### 1. Sum of First N Numbers

This program calculates the **sum of the first N natural numbers** using a `for` loop.

Example:
If `n = 5`

Output:
Sum = 15

---

### 2. Multiplication Table

This program prints the **multiplication table of a given number** from 1 to 10.

Example:
For `12`

12 × 1 = 12
12 × 2 = 24
...
12 × 10 = 120

---

### 3. Prime Number Check

This program checks whether a number is **prime or not**.

A prime number is a number that is divisible only by **1 and itself**.

Example:
Input: 5
Output: It is a prime number.

---

### 4. Factors of a Number

This program finds and prints **all factors of a given number**.

Example:
For `128`

Factors:
1, 2, 4, 8, 16, 32, 64, 128

---

### 5. Sum of Digits of a Number

This program calculates the **sum of all digits in a number**.

Example:
Input: 1234

Calculation:
1 + 2 + 3 + 4 = 10

Output: 10

---

### 6. Armstrong Number Check

This program checks whether a number is an **Armstrong number**.

An Armstrong number is a number that is equal to the **sum of the cubes of its digits**.

Example:

153 →
1³ + 5³ + 3³ = 153

Output: It is an Armstrong Number.
