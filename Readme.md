# Laundry Wallah - CSS Focus Navigation

A responsive navigation UI built with HTML and CSS that demonstrates the use of the `:focus-within` pseudo-class to create a mobile sidebar menu without JavaScript.

## Features

- Responsive Navigation Bar
- CSS-Only Sidebar Menu
- `:focus-within` Based Interaction
- Mobile-Friendly Design
- Flexbox Layout

## Key Concept

```css
.username:focus-within .side-bar {
    display: block;
}

# When the menu button receives focus, the sidebar becomes visible, creating an interactive navigation experience using only CSS.
