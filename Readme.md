# 🧺 Laundry Wallah Website

A responsive laundry service landing page built using **HTML + CSS (Flexbox)**.

---

## 🚀 Features

* Modern **Flexbox layout**
* Fully **responsive design**
* Works on:

  * 💻 Desktop
  * 📱 Mobile
  * 📲 Tablet
* Clean and minimal UI

---

## 📂 Project Structure

```
Laundry-Wallah/
│── index.html
│── style.css
│── wm.png
```

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox + Media Queries)

---

## 📱 Responsive Design

* Desktop → Side-by-side layout
* Tablet → Stacked layout
* Mobile → Fully centered layout with vertical navbar

---

## ▶️ How to Run

1. Download the project
2. Open `index.html` in browser
