# JavaScript DOM Interaction

## Overview

This project demonstrates basic **DOM manipulation and event handling in JavaScript**.

## Features

* Clicking a box adds a unique class (`box_1`, `box_2`, etc.).
* User can enter their name in an input field.
* When the **Greet** button is clicked, the name is displayed in the greeting header.

## Concepts Used

* `querySelectorAll`
* `getElementById`
* `addEventListener`
* Template literals
