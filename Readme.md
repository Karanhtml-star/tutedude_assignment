# 🚀 AI SaaS Hero Landing Page

A modern landing page built with **HTML** and **Tailwind CSS** inspired by AI-powered productivity platforms. The project features a clean navigation bar, a hero section, floating information cards, and a fixed support button.

## ✨ Features

- Modern and minimal UI
- Sticky navigation bar
- Hero section with call-to-action buttons
- Dashboard preview image
- Floating feature cards
  - Task Progress
  - Project Status
  - Team Activity
- Fixed support/chat button
- Built entirely using Tailwind CSS utility classes
- Beginner-friendly project structure

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- SVG Icons

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/ai-landing-page.git
```

### 2. Navigate to the project

```bash
cd ai-landing-page
```

### 3. Install Tailwind CSS (if you want to modify the styles)

```bash
npm install
```

### 4. Build Tailwind CSS

```bash
npx @tailwindcss/cli -i ./src/input.css -o ./output.css --watch
```

### 5. Open the project

Simply open **index.html** in your browser or use the Live Server extension in VS Code.
