🚀 Responsive Startup Landing Page

A modern and responsive startup landing page built using HTML and Tailwind CSS. This project showcases a clean hero section, responsive navigation, and feature cards, making it a great starting point for SaaS, startup, or product websites.

🎨 Tailwind CSS
If you're using the Tailwind CLI:
Install dependencies

npm install

Start Tailwind Watch

npx @tailwindcss/cli -i ./src/input.css -o ./output.css --watch
