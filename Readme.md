# JavaScript Promise Division Assignment

## Overview

This program takes two numbers as input and performs **division using a JavaScript Promise**. It demonstrates basic concepts of **Promises, arrow functions, and error handling**.

## Working

1. The user enters two numbers using `prompt()`.
2. A function calculates the division of the numbers.
3. A **Promise** checks if the second number is `0`.
4. If valid, the promise **resolves** and prints the result.
5. If the second number is `0`, the promise **rejects** with an error message.

## Concepts Used

* Promises (`resolve`, `reject`)
* Arrow functions
* User input with `prompt()`
* Error handling with `.catch()`

## Example Output


Enter first number: 10
Enter second number: 2

The division of two numbers is: 5
