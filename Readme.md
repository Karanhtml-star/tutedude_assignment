# JavaScript Array Operations Assignment

## Overview

This program performs basic operations on an array using JavaScript functions.

Array used:

```
[4, 8, 2, 11, 6, 7, 10]
```

## Functions

**1. Maximum Number**
Finds the largest element in the array.

**2. Sum of Elements**
Calculates the total sum of all elements.

**3. Count Odd Numbers**
Counts how many odd numbers exist in the array.

## Concepts Used

* Arrays
* Functions
* For loops
* Conditional statements

## Output

```
Maximum number: 11
Sum of all Elements in array: 48
Number of odd elements in array: 2
```
