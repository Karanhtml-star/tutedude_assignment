# 🖼️ Image & Button Layout

A simple CSS layout showing a centered image with a full-width button below it.

## 🚀 Features

* Centered layout using margins
* No vertical scrollbar
* Responsive image
* Gradient button (orange → yellow → green)

## 🛠️ Tech Used

* HTML5
* CSS3

## ▶️ Run

Open `index.html` in your browser.
